# Cascade Chaos

Cascade Chaos is a quick online party game where players read HTML/CSS code and draw what they think the final page will look like.

## How to play

1. Create or join a room.
2. Choose a display name.
3. Wait in the lobby until the round starts.
4. In each round, code appears on the screen.
5. Draw your best prediction before the timer ends.
6. The real rendered page is revealed.
7. Vote for the drawing that matches the real design most closely.
8. The player with the most points after all rounds wins.

## What makes it fun

- Fast, creative drawing rounds
- A surprise reveal of the actual page design
- Voting for the most accurate prediction
- Friendly competition with a live leaderboard
- Simple play; no account or login needed

## Goal

Try to interpret code visually and draw the closest match. The more accurate your sketch, the better your score.

## Note

This game is built for friends and party play. If you enjoy quick puzzles and drawing challenges, Cascade Chaos is designed to keep rounds lively and surprising.
